# React Native Mobile App
This folder will contain the source code for the mobile application built with React Native.

## Initial Setup
- Use React Native CLI or Expo to initialize the app.
- Integrate Google Maps for Vuga visualization.
- Connect to the backend via REST API.

## Structure
- `/src` — App source code
- `/assets` — Images and other assets

---

# Getting Started
1. Install dependencies: `npm install` or `yarn install`
2. Run the app: `npx react-native run-android` or `npx react-native run-ios` (for CLI)
